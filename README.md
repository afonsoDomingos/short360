# Shorts360

Criador automático de shorts de vídeo - Divida seus vídeos automaticamente em clips curtos para redes sociais.

## 🚀 Funcionalidades

- **Upload simples**: Arraste e solte ou clique para selecionar seu vídeo
- **Configuração flexível**: Escolha a duração de cada short (15s, 30s, 45s ou 60s)
- **Processamento automático**: O vídeo é dividido automaticamente em múltiplos shorts
- **Download fácil**: Baixe cada short individualmente ou todos de uma vez
- **Interface limpa**: Design minimalista em branco, fácil de usar

## 📦 Como usar

1. Abra o aplicativo no navegador
2. Arraste seu vídeo para a área de upload ou clique para selecionar
3. Escolha a duração desejada para cada short
4. Clique em "Gerar Shorts"
5. Aguarde o processamento
6. Baixe os shorts gerados individualmente ou todos de uma vez

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
- MediaRecorder API
- Canvas API

## 📱 Deploy

Este projeto está configurado para deploy na Vercel. Basta:

1. Conectar seu repositório do GitHub à Vercel
2. O deploy será automático

Ou manualmente:

```bash
npm install -g vercel
vercel
```
